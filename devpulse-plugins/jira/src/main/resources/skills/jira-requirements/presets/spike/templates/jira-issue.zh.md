# 技术调研 Issue 模板

将下方完整代码块内容保存为 `work\issue.md`。选择项目实际支持的 Issue 类型，并在提交前替换所有 `{{...}}`。

```markdown
---
project: "{{project_key}}"
issuetype: "{{issue_type_name}}"
summary: "{{confirmed_summary}}"
priority: ""
epic: ""
story-point: ""
bodyFormat: markdown
---

## 调研问题
{{需要回答的问题}}

## 背景与动机
{{调研背景与原因}}

## 范围与时间盒
{{范围、非目标和时间盒}}

## 调研方法
{{研究或实验计划}}

## 方案与权衡
{{候选方案及评估标准}}

## 发现与建议
{{基于证据的发现和建议}}

## 交付物与后续工作
{{决策记录、原型或后续 Issue}}
```
